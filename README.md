# 🚁 DJI Mavic 4 Pro - Product Preview Page

A modern, responsive product preview page showcasing the DJI Mavic 4 Pro drone with an elegant design and smooth user experience.

## ✨ Features

- 🎨 **Modern UI Design** - Clean and professional interface with smooth animations
- 📱 **Responsive Layout** - Optimized for all screen sizes
- 🎯 **Product Showcase** - Detailed product information with high-quality images
- 📊 **Comparison Table** - Side-by-side feature comparison with competitors
- ⭐ **Customer Reviews** - Interactive review section with ratings and testimonials
- 🛍️ **Related Products** - Product recommendations and accessories
- 🎭 **Smooth Animations** - Hover effects and transitions for better UX

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with flexbox and animations
- **Font Awesome** - Icon library for beautiful icons
- **Google Fonts** - Arimo font family for typography

## 🚀 Getting Started

### Prerequisites

No dependencies required! Just a modern web browser.

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Navigate to the project directory:
```bash
cd Preview-Product-main
```

3. Open `index.html` in your web browser:
   - Simply double-click the file, or
   - Use a local server (recommended):
```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```

4. Visit `http://localhost:8000` in your browser
